# AI Resume Customizer (ThePrepLab Assignment)

An AI-powered web application that takes a Job Description and a candidate's resume (PDF/DOCX), analyzes the semantic alignment using LLMs, and generates a tailored resume optimized for ATS systems.

## Tech Stack

- **Frontend:** Next.js (App Router), TypeScript, Tailwind CSS
- **Backend:** Python, FastAPI, PyPDF2, python-docx, Google Gemini API

## Local Setup Instructions

1. Clone the repository.
2. Set up the Python backend inside the `backend/` directory using virtual environment and `requirements.txt`.
3. Set up the Next.js frontend inside the `frontend/` directory using `npm install`.
4. Configure `.env` files with your API keys.
